# 网络安全自学路线图（2026.10 – 2028.6）

> **投入**：每晚 20:00–21:30 固定 90 分钟 + 21:30–22:00 弹性收尾区；每周至少 6 天；寒暑假为加速档。
> **目标检验（2027 年 9 月秋招）**：简历具备"四件套"——工具作品、writeup、CTF 经历、实习/护网经历；能把常见 Web 漏洞讲清原理并当场复现。
> **三条原则**：① 聚焦 Web 安全（与前端底子直接衔接）；② Python 为第二主线；③ 输出驱动，每两周一次公开产出。

## 前置假设

1. 20:00–21:30 为硬性学习时间；21:30–22:00 弹性区只做收尾，不开新任务。
2. 每周至少 6 天；允许丢 1 天不补；极忙/生病日切换"最低维护模式"（30 分钟）。
3. 英语由独立计划负责；本表只保留"四级报名窗口"这条外部死线。
4. 毕业直接就业，不考研。
5. 设备：16GB 内存笔记本（C 盘约 300GB 可用）；方案 = 单台 Kali 虚拟机 + 云端靶场，不升级硬件。
6. 预算：尽量零起步，全部使用免费资源；百元级支出自筹到位后按需解锁。

## 使用说明

- 本仓库约定：`README.md` 存计划（只在需要调整时修改）；`PROGRESS.md` 存执行记录（每周日复盘后更新）。
- 每 4 周对照"里程碑与止损"校准一次；假设变化（时间、预算、方向感觉）时只调整对应模块，不推倒重来。
